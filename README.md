# Trading Konsole releases

Installers, release notes and SHA-256 fingerprints of the Trading Konsole
desktop app for macOS and Windows. The source code is not here: this
repository exists so that downloads and automatic updates have a public home.

- Download page and first-launch guide: https://tradingkonsole.com/download/
- Latest release: https://github.com/andreapinti/trading-konsole-releases/releases/latest

Each release carries `SHA256SUMS-<platform>.txt`: compare the fingerprint of
the file you downloaded with the one listed there.
